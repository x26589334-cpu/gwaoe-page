시험 당일에도 잃는 점수가 있습니다

시험 당일 실수 줄이기

  • 발문에 표시 — "옳지 않은 것" 같은 조건에 반드시 표시합니다.
  • 시간 절반 지점 확인 — 중간 시점에 어디까지 왔는지 점검합니다.
  • 막히면 넘기기 — 30초 안에 실마리가 없으면 표시하고 넘어갑니다.
  • 답안 옮기는 시간 확보 — 마지막 3분은 검토와 마킹에 씁니다.

남은 기간 배분

시험 운영은 평소 문제를 풀 때부터 같은 방식으로 연습해야 시험장에서 나옵니다.

  • 1주차 — 범위 정리와 함께 발문 표시 습관을 들입니다
  • 2주차 — 문제를 풀 때 시간을 재기 시작합니다
  • 3주차 — 기출을 실전과 같은 시간으로 풀어봅니다
  • 마지막 주 — 실수했던 유형만 점검하고 컨디션을 관리합니다
